## Provenance and immutable data

The reviewed M3 commit `0706af3d714e8c2701691a19a0c663ae7b749c88` and integration
`d9c3b65b7d20e385c899b5e629f80a3510f1244d` were already task ancestors. Source
checkout branch and task AGENTS.md were verified before work. The oracle is native
Alone2/Format7zF, not the small C SDK and not a substituted system 7z.

[Manifest](../../../.github/tests/migration/b01/manifest.json) has schema_version=1,
immutable member SHA-256, generator/version/license/provenance, per-fixture
list/test/extract scope and native report paths. The payload is the numeric byte
sequence `bytes(range(256))*16`; no downloaded/copyrighted third-party payload,
user archives, passwords, or secrets are involved. The output bytes are committed,
not regenerated during tests. Generator licensing does not transfer to archive
payloads; engine and generator source licenses are unchanged. Fixture metadata's
license description deliberately makes no claim of a third-party license grant.

Independent CPython 3.11.16 stdlib writers supplied ZIP Store/Deflate/BZip2/LZMA,
USTAR, gzip, bzip2, xz and LZMA-alone archives, including a tar.gz nested payload
and a ZIP under a non-archive extension. Stdlib readers additionally check newly
created ZIP/tar/gzip/bzip2/xz bytes against the source, so those probes are not just
a coordinated legacy writer/reader round trip. Python version alone does not pin
linked zlib/liblzma builds: the committed bytes and digests, rather than hypothetical
byte-identical regeneration on another machine, are the reproducibility contract.

Retained Alone2 26.03 supplied immutable 7z Copy/LZMA2 and 1 KiB split-volume bytes.
These 7z fixtures prevent subsequent drift but are NOT external-writer 7z
interoperability evidence. Manifest authoring commands, executable digest and
actual version output are preserved. `generate.py` is initial one-shot authoring
provenance, not a CI regeneration/update mechanism; it refuses an existing fixture
directory. The two supplemental final-next-header/tail-truncation recipes are
recorded precisely in the manifest. All mutations happened before freezing any
B01 oracle; no M1 expected values were changed.

## Execution and stable comparison

[Capture harness](../../../.github/tests/migration/b01/capture.py) executes 96
operations in a disposable directory, with EOF stdin and per-command timeout.
Each command retains exact argv, raw stdout/stderr as Base64 bytes and raw exit.
Base64 is a lossless storage encoding, not redaction or normalized output.
`observations` stores ordered listing property blocks, exit codes, literal CLI
error-label arrays and extracted file sizes/hashes, including effects of failed
extractions. Names are not used as engine identity; these ASCII-only measurements
do NOT implement ArchiveId/Generation/EntryId or EngineText/NativePath contracts.

Only the derived listing view substitutes temporary roots and executable paths
and converts path separators; raw console bytes are retained unchanged. Volatile
banners/timings and filesystem metadata are outside the comparator. Same-platform
OS/architecture, manifest hash, full native registration text and observations
must match. There is no cross-platform borrowing of native goldens.

The local capture and independent repeat returned 96 operations and matched.
Six negative controls rejected temporary exit, diagnostics, extracted-file,
platform, registration and immutable-fixture byte drift; the unchanged control
passed. Existing M1 Linux frozen comparison passed 41 operations. The test harness
refuses writing a capture anywhere inside the checked-in corpus or onto --expect.

## Capability inventory and unresolved qualification

[Inventory](../../../.github/tests/migration/b01/inventory.json) enumerates every
format registration row from actual local `7zz i`, not a handwritten supported
format list. Every format has covered/unqualified status, exact registration flags,
explicit fixture list and `production_release=false`. A covered row means ONLY
those fixture methods/operations, never all variants. The unsupported section
names the measured ZIP method value. Full native codec/hasher registration rows
are also frozen in each capture. Enumeration is NOT proof every handler works.

Required gaps are explicit: remaining format/method variants, external
7z/RAR/CAB/ISO/WIM interoperability fixtures, RAR multipart, arbitrary automatic
nested handler chains, native Windows GUI product-vs-Alone2 capabilities, and
lossless numeric structured engine outcomes. No required unqualified case may
release affected production. Additional ordinary fixture engineering remains
necessary; it is not waived by these successful measurements.

### Decision needed: meaning of structured errors before the facade

M2 [error contract](../architecture-target.md#5-errors-progress-prompts-and-cancellation)
requires original HRESULT bits, numeric NOperationResult, CArcErrorInfo
flags/definedness and ordered item results. Alone2 console output does not expose
all of these. The corpus deliberately records `domain=legacy-cli-text` and NULL
numeric fields with an unavailable reason. It does not synthesize codes from
English messages or exit=2. This is structured CLI evidence, not the M2 lossless
engine outcome model. B01 is upstream of bridge qualification, so using the future
facade to satisfy an already-required B01 result would not be valid dependency
ordering.

The task needs an explicit scope/contract decision before full acceptance:

1. Retain the complete B01 requirement and authorize a test-only retained-engine
   numeric error observer as a separate implementation/independent-review step
   before B01 closure. Recommended if B01 requires M2-native numeric results;
   preserves the existing gate and requires additional test instrumentation.
2. Explicitly scope B01 to the bounded immutable CLI corpus and registration
   inventory, with named, dependency-enforced numeric/error and remaining-format
   qualifications before affected production. Requires orchestrator/architect
   graph/spec review; this author cannot silently narrow or release the gate.
3. Defer B01 and affected descendants without changing scope; preserve these
   partial artifacts, continue independent eligible cards, and release nothing.

Neither notification delivery, CI success nor a generic approval to continue
constitutes a decision on this ambiguity. This document and code still require
independent review after the scope is resolved.

container CRLF is normalized to LF by the oracle-only attributes, preserving all
captured values; fixture bytes are explicitly `-text`.
